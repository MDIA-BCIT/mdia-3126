# Midterm practice materials for MDIA-3126

Inside the `/practice-components` folder, you'll find several components to build out.

These components will not be the same as the ones on the midterm, but are similar in levels of complexity. I have helped you by giving each of the components names, on the midterm you will be required to identify and name your own components.

See [BEM](https://bem.info/en/methodology/css/) for naming conventions and a general study guide.

(Hint: there is a compound/complex component in the practice components that uses another practice component inside it.)
